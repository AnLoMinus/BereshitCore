# 🧭🔥 חזון המערכת

**BereshitCore (BC)** הוא מאגר חי שמטרתו:

* 📖 לאסוף פירושים על מעשה בראשית
* 🧠 לייצר חידושים רב־שכבתיים (פשט–רמז–דרש–סוד)
* 🔗 לחבר רעיונות לרשת ידע אחת
* ⚡ להפוך את פרשת בראשית למערכת חשיבה פעילה

---

# 🏗️📂 מבנה המאגר (Architecture)

## 📁 1. שכבת פסוקים (Core Layer)

כל פסוק = יחידה עצמאית:

```
/BC/
  /01_Bereshit/
    /01_01/
    /01_02/
    /01_03/
```

בתוך כל פסוק:

* 📜 טקסט הפסוק
* 💡 חידושים
* 🔥 סודות
* 🧠 ניתוחים
* 🎯 יישומים

---

## 🧩 2. שכבת עומק פרשני

כל רעיון מתויג:

* 🟢 פשט – משמעות ישירה
* 🔵 רמז – עומק לשוני / מספרי
* 🟣 דרש – הרחבה רעיונית
* 🔴 סוד – מבנה רוחני פנימי

---

## 🔗 3. שכבת חיבורים (Knowledge Web)

כל חידוש מתחבר ל:

* פסוקים אחרים
* מושגים חוזרים (אור, מים, זמן, תוהו)
* תבניות חשיבה

➡️ נוצר **מוח ידע חי** 🧠⚡

---

## 🧠 5. שכבת ניתוח על־מודעת

* 🔢 גימטריה
* 🔤 ניתוח אותיות

* 🧬 השוואה למבני טבע ומדע
* ⚖️ תובנה מוסרית
